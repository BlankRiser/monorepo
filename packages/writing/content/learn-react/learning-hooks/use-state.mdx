In React 19, automatic batching applies uniformly across all execution contexts, including asynchronous promises, timeouts, and native DOM listeners.

```tsx
function Counter() {
  const [count, setCount] = useState(0);
  const [flag, setFlag] = useState(false);

  function handleClick() {
    // Both updates are batched into a single render pass
    setCount((c) => c + 1);
    setFlag((f) => !f);
  }

  return <button onClick={handleClick}>Tick</button>;
}
```
