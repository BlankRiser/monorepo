## The Modern Hook Primitives

In React 19, the boundary between compile-time optimization and runtime execution has evolved. Memoization directives (`useMemo`, `useCallback`) are largely automated by the compiler, allowing hooks to focus purely on state transitions and side effect synchronization.

```tsx
import { use, Suspense } from "react";

function UserProfile({ userPromise }: { userPromise: Promise<User> }) {
  const user = use(userPromise);
  return <div>{user.name}</div>;
}
```
